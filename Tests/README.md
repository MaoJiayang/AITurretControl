# TargetTracker 测试项目使用说明

## 项目说明

这是一个独立的测试项目，用于测试 `TargetTracker.cs` 模块的预测性能。

## 项目结构

```
Tests/
├── TargetTrackerTests.csproj  # 项目文件（使用MDK2引用）
├── Program.cs                 # 主测试程序
├── 轨迹生成器.cs              # 生成各种运动轨迹
└── README.md                  # 本文件
```

## 运行方法

### 1. 命令行运行

在 `AITurretControl` 根目录下执行：

```powershell
cd Tests
dotnet build
dotnet run
```

### 2. Visual Studio 运行

1. 在 VS Code 或 Visual Studio 中打开 `Tests` 文件夹
2. 按 F5 运行或使用 `dotnet run`

## 测试内容

程序会自动执行以下4种测试：

1. **直线匀速运动** - 测试线性预测能力
   - 速度: (100, 50, 30) m/s
   - 时长: 10秒

2. **二次曲线（匀加速）** - 测试加速度处理
   - 初速度: (50, 0, 0) m/s
   - 加速度: (0, 10, 0) m/s²
   - 时长: 10秒

3. **圆周运动** - 测试圆周运动预测
   - 半径: 500米
   - 角速度: 0.1 rad/s
   - 时长: 30秒

4. **螺旋运动** - 测试复杂运动
   - 半径: 300米
   - 角速度: 0.15 rad/s
   - 轴向速度: 20 m/s (Z轴)
   - 时长: 20秒

## 输出结果

程序会在 `Tests/bin/.../TestResults/` 目录下生成CSV文件：

- `直线匀速运动.csv` - 直线运动详细数据
- `二次曲线匀加速.csv` - 二次曲线详细数据
- `圆周运动.csv` - 圆周运动详细数据
- `螺旋运动.csv` - 螺旋运动详细数据
- `汇总统计.csv` - 所有测试的统计汇总

### CSV文件格式

每个CSV文件包含以下列：

- 观测时间(ms) - 当前观测的时间戳
- 预测时长(ms) - 向前预测的时间长度
- 真实X/Y/Z - 真实的未来位置
- 预测X/Y/Z - 预测的未来位置
- 位置误差 - 预测位置与真实位置的距离误差
- 线性误差 - 线性预测模型的误差
- 圆周误差 - 圆周预测模型的误差
- 组合误差 - 组合预测的误差
- 线性权重 - 线性模型的权重
- 圆周权重 - 圆周模型的权重

## 数据可视化

### 使用Python脚本自动生成图表

1. **安装Python依赖**（首次运行）：
```powershell
cd Tests
uv venv
uv pip install pandas matplotlib
```

2. **运行可视化脚本**：
```powershell
uv run python visualize_results.py
```

脚本会自动生成以下图表到 `TestResults/` 目录：
- `直线匀速运动_分析.png` - 直线运动完整分析（4个子图）
- `二次曲线匀加速_分析.png` - 二次曲线完整分析
- `圆周运动_分析.png` - 圆周运动完整分析
- `螺旋运动_分析.png` - 螺旋运动完整分析
- `汇总对比.png` - 所有测试的误差对比
- `统计对比.png` - 平均误差和最大误差柱状图

每个分析图包含：
- **位置误差曲线** - 预测位置与真实位置的距离误差
- **预测误差对比** - 线性、圆周、组合三种预测模型的误差对比
- **权重自适应变化** - 观察系统如何动态调整线性和圆周权重
- **3D轨迹对比** - 真实轨迹与预测轨迹的3D可视化

### 手动使用Excel可视化
1. 打开CSV文件
2. 创建散点图，绘制真实位置 vs 预测位置
3. 创建折线图，观察误差随时间的变化

### Python (matplotlib)
```python
import pandas as pd
import matplotlib.pyplot as plt

# 读取数据
df = pd.read_csv('直线匀速运动.csv')

# 绘制位置误差
plt.plot(df['观测时间(ms)'], df['位置误差'])
plt.xlabel('时间 (ms)')
plt.ylabel('位置误差 (m)')
plt.title('预测误差随时间变化')
plt.show()

# 绘制权重变化
plt.plot(df['观测时间(ms)'], df['线性权重'], label='线性')
plt.plot(df['观测时间(ms)'], df['圆周权重'], label='圆周')
plt.legend()
plt.show()
```

## 修改测试参数

可以在 `Program.cs` 中修改测试参数：

```csharp
// 修改轨迹参数
var 轨迹 = 轨迹生成器.生成圆周运动轨迹(
    Vector3D.Zero,
    500,    // 修改半径
    0.1,    // 修改角速度
    new Vector3D(0, 0, 1),
    new Vector3D(1, 0, 0),
    30.0,   // 修改持续时间
    100     // 修改采样间隔
);

// 修改预测时长
执行预测测试(轨迹, 结果, 2000); // 改为预测2秒后
```

## 注意事项

1. 本测试项目已被主项目的 `.csproj` 排除，不会影响游戏脚本的生成
2. 使用的是与主项目相同的 MDK2 引用，无需额外配置
3. 预测需要至少4个历史点才能开始，前几个点会被跳过
